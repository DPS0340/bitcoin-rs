- `Tx::base_size()`, `Tx::total_size()`, `Tx::weight()` (BIP141 base*3+total),
  `Tx::vsize()` (weight/4 ceil) via a zero-alloc `CountWriter`.

  decode divergence (`DecodeError::SuperfluousWitness` — native follows Core's
  "superfluous witness record" rejection; rust-bitcoin 0.32 accepts it on

  (e.g. `fuzz/corpus/block_decode/0ca7ee0a…`) hit it. Any other oracle/native
  verdict mismatch still fails the gate.

  `count_segwit` (p2wpkh=1; p2wsh → accurate witness-script count via

## Re-runnable per-pattern notes for the remaining crates

Mechanical rewrite table (old → new), verified in phase 1:

| rust-bitcoin pattern | native replacement |
|---|---|
| `bitcoin::Transaction {version: transaction::Version::TWO, lock_time: absolute::LockTime::ZERO, input: vec![TxIn{previous_output, script_sig: ScriptBuf, sequence: Sequence(x), witness: Witness}], output: vec![TxOut{value: Amount::from_sat(v), script_pubkey}]}` | `primitives::Tx {version: 2, inputs: vec![TxIn{previous_output, script_sig: Vec<u8>, sequence: u32, witness: Vec<Vec<u8>>}], outputs: vec![TxOut{value: u64, script_pubkey: Vec<u8>}], lock_time: u32}` |
| `tx.compute_txid() / compute_wtxid()` | `tx.txid() -> Txid` / `tx.wtxid() -> Wtxid` |
| `tx.vsize()/total_size()/weight().to_wu()/base_size()` | same names on `Tx`, plain integers |
| `tx.total_sigop_cost(\|_\| None)` | `bitcoin_rs_script::sigops::count_tx_legacy(&tx)` (add `bitcoin-rs-script` dep to mempool) or `count_block` |
| `tx.input` / `tx.output` fields | `tx.inputs` / `tx.outputs` |
| `input.sequence.0` | `input.sequence` (plain u32) |
| `bitcoin::Txid::from_byte_array([x;32])` | `Txid(Hash256::from_le_bytes(&[x;32]))` |
| `bitcoin::OutPoint{txid, vout}` | `primitives::OutPoint::new(txid, vout)` (same 36-byte layout; `as_bytes()` for storage keys) |
| `txid.as_ref()/as_byte_array()` (32B) | `txid.as_bytes()` (`&[u8;32]`, LE consensus order) |
| `bitcoin::hashes::Hash::hash(bytes)` / sha256d | `primitives::encode::double_sha256(bytes) -> Hash256` |
| `Hash::to_byte_array()/as_byte_array()` | `Hash256::to_le_bytes()/as_byte_array()` (LE); display via `to_string_be()` |
| `bitcoin::consensus::serialize(&tx\|block)` | `primitives::encode::consensus_bytes(&value)` |
| `bitcoin::consensus::deserialize::<T>(bytes)` | `primitives::encode::deserialize::<Tx\|Block\|Header>(bytes)` (`DecodeError`) |
| `block.txdata` | `block.txs` |
| `block.check_witness_commitment()` | NOT yet ported (apply.rs uses it) — port as native helper: find `OP_RETURN PUSH36 0xaa21a9ed…` in coinbase, compare with header merkle root of wtxids |
| `bitcoin::blockdata::constants::genesis_block(network)` | `network.genesis_block()` (native); `genesis_block_hash()` existed |
| `bitcoin::Network::{Bitcoin,Testnet,Testnet4,Signet,Regtest}` | `primitives::Network::{Mainnet,Testnet3,Testnet4,Signet,Regtest}` (mapping fn in node/src/sync.rs exists — delete it, use native) |
| `bitcoin::merkle_tree::calculate_root(leaves)` | port: double-SHA256 pairwise fold over LE txid bytes, duplicate-last on odd levels (Core/rust-bitcoin semantics) — needed by mining/template.rs and consensus verify_block (verify_block.rs already has a native `merkle_root_and_mutation`) |
| `bitcoin::pow::CompactTarget::from_consensus(bits)` | plain `u32 bits` (native `Header.bits`) |
| `bitcoin::Amount::from_sat(x)` | `x: u64` |
| `bitcoin::FeeRate` (sat/kvB) | `u64` sat/kvB + `script::minimal_non_dust(&[u8], fee)` for dust |
| `bitcoin::VarInt` sizes in policy code | `primitives::varint` |
| `bitcoin::script::Builder().push_int(n).push_slice(..).into_script()` | `script::push_int(n)` + `script::push_data(bytes)` concatenated (`Vec<u8>`) |
| `bitcoin::sighash::SighashCache` (all callers) | `primitives::SighashCache` — `legacy_signature_hash(idx, script_code: &[u8], flags: u32)`, `segwit_v0_signature_hash(idx, script_code, value: u64, Sighash)`, `taproot_signature_hash(idx, prevouts: &[TxOut], annex: Option<&[u8]>, leaf_hash_code_separator: Option<(Hash256,u32)>, Sighash)`; types via `Sighash::{All..Default, to_u8(), from_consensus_u8()}` |
| `bitcoin::ecdsa::Signature::from_slice` (bip66 DER check) | port BIP66 `IsValidSignatureEncoding` structurally (0x30 len 0x02 r 0x02 s; sighash byte separate) — no crypto needed |
| `bitcoin::p2p::*` (Magic, ServiceFlags, NetworkMessage, Inventory, VersionMessage, AddrV2…) | RETAINED (p2p envelope/framing; plan: "message framing untouched", 4b owns the contract). Only `tx`/`block`/`headers` payloads migrate to native types. |
| `bitcoin::secp256k1::*` | direct `secp256k1::` crate (not rust-bitcoin; untouched rule) |
